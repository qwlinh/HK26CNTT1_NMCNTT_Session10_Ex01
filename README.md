# YÊU CẦU ĐẦU RA

## Phần 1: Phân tích

- Lỗi không hiển thị mục lục: Do bạn Nam dùng định dạng thủ công thay vì dùng Heading Styles có sẵn của hệ thống.

- Lỗi hiện đoạn văn 5 trang trong mục lục: Do Nam lỡ quét khối nhãn Heading 1 trùm lên toàn bộ đoạn văn bản dài phía dưới thay vì chỉ chọn phần tiêu đề ngắn.

## Phần 2: Sửa lỗi

1 Khắc phục lỗi đoạn văn 5 trang: Bôi đen đoạn văn bản bị dán nhãn nhầm.

2 Gán lại Heading chuẩn cấp bậc:

- Chọn tiêu đề lớn 
- Chọn tiểu mục con

 3: Chèn và Cập nhật Auto TOC:

- Đặt con trỏ tại vị trí muốn tạo mục lục 

Khi thay đổi nội dung hoặc thêm trang, nhấp chuột vào bảng mục lục 
→ Chọn Update Table → Update entire table để cập nhật lại số trang chuẩn xác
